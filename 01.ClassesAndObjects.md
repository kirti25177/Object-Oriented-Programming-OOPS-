## Problem 1

Create a `Rectangle` class that stores the length and breadth of a rectangle. Read both dimensions, calculate the area and perimeter, and display the results.

## Input Format

Two space-separated integers representing the length and breadth.

## Output Format

Print the area on the first line and the perimeter on the second line.

## Example

**Input**
```text
5 3
```

**Output**
```text
Area: 15
Perimeter: 16
```

## Approach

- Store the length and breadth as data members.
- Calculate area using `length * breadth`.
- Calculate perimeter using `2 * (length + breadth)`.
