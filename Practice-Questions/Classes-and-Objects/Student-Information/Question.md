# Student Information

## Problem Statement

Nial is developing a student information system. Create a class named `Input` to store a student's name and roll number. In the `main()` function, read the student's details and display them.

## Input Format

The input consists of:
- The student's name as a string.
- The student's roll number as an integer.

## Output Format

Print the student's details in the format:

`X: Y`

Where `X` is the roll number and `Y` is the student's name.

## Constraints

- The student's name must be a non-empty string.
- The roll number must be a non-negative integer.
- `1 ≤ roll number ≤ 1000000`

## Sample Input 1

```text
Jane
158
```

## Sample Output 1

```text
158: Jane
```

## Sample Input 2

```text
John
8486
```

## Sample Output 2

```text
8486: John
```
