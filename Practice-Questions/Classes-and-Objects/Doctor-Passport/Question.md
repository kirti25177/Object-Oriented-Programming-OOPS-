# Doctor Passport

## Problem Statement

Mithra is working on a hospital management system. Implement a feature that allows doctors to enter their information and generate a doctor's passport containing their name, address, and ward number.

Create a class named `Doctor` to store the doctor's information. Create a `Doctor` object with the provided details, assign its information to a Doctor Passport object, and display the doctor's name, address, and ward number from the passport object.

## Input Format

- The first line contains a string representing the doctor's name.
- The second line contains a string representing the doctor's address.
- The third line contains an integer representing the ward number.

## Output Format

Print the doctor's information in the following format:

- `Name: <name>`
- `Address: <address>`
- `Ward Number: <ward number>`

## Sample Input

```text
Dr. Sharma
Model Town, Ludhiana
12
```

## Sample Output

```text
Name: Dr. Sharma
Address: Model Town, Ludhiana
Ward Number: 12
```
