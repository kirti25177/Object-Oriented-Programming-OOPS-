# Date and Leap Year

## Problem Statement

You are developing a simple date management system for a small library. Each entry in the library's catalog records the date when a book was added.

Create a class named `Date` with attributes for the day, month, and year. Read a date from the user, display it, and determine whether the year is a leap year.

## Input Format

The input consists of three space-separated integers representing the day, month, and year.

## Output Format

The first line displays the date in the format:

`day month year`

The second line displays whether the year is a leap year, using one of these formats:

- `<year> is a leap year`
- `<year> is not a leap year`

## Sample Input 1

```text
29 2 2024
```

## Sample Output 1

```text
29 2 2024
2024 is a leap year
```

## Sample Input 2

```text
15 8 2023
```

## Sample Output 2

```text
15 8 2023
2023 is not a leap year
```
