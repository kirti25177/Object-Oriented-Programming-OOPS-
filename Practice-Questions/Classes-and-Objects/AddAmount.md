# AddAmount — Banking Application

## Problem Statement

Guna is developing a banking application that allows customers to deposit money into their accounts. Each customer starts with an initial balance of ₹50.

Create a class named `AddAmount` to represent the deposit transaction. Read the additional deposit amount, calculate the total balance, and display the final amount.

## Input Format

A single integer representing the deposit amount.

## Output Format

Print an integer representing the total balance after the deposit.

## Sample Input
```text
200
```

## Sample Output
```text
250
```

## Concepts Used

- Classes and Objects
- Default Constructor
- Parameterized Constructor
- Constructor Overloading
