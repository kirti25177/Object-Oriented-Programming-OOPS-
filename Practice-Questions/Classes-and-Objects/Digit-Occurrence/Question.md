# Digit Occurrence

## Problem Statement

Guna wants to create a program that counts how many times a particular digit appears in a given positive integer.

Create a class named `Occurrence` containing two data members:

- A positive integer provided by the user.
- A digit (from 0 to 9) whose occurrence needs to be counted.

Read the input values, store them in an object of the class, and determine how many times the given digit appears in the number.

**Note:** The digit `0` must also be counted correctly. For example, in `1002`, the digit `0` appears 2 times.

## Input Format

- The first line contains a positive integer `n`.
- The second line contains a single digit (0–9) whose occurrence needs to be counted.

## Output Format

Print an integer representing the total number of occurrences of the given digit in the number.

## Sample Input 1

```text
1002
0
```

## Sample Output 1

```text
2
```

## Sample Input 2

```text
12345
3
```

## Sample Output 2

```text
1
```
