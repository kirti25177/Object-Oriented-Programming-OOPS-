# Day of the Week

## Problem Statement

Harish is learning about the days of the week. He wants to create a program that accepts a number representing a day of the week and prints the corresponding day's name.

Create a class named `dayOfWeek` to store the input day number and display the corresponding day name. If the entered number is outside the range 1 to 7, print `Invalid`.

## Input Format

The input consists of an integer `N` representing the day of the week.

## Output Format

Display the corresponding day name according to the following mapping:

| Number | Day |
|---:|---|
| 1 | Sunday |
| 2 | Monday |
| 3 | Tuesday |
| 4 | Wednesday |
| 5 | Thursday |
| 6 | Friday |
| 7 | Saturday |

For any value less than 1 or greater than 7, print `Invalid`.

## Constraints

`0 ≤ N ≤ 100`

## Sample Input 1

```text
3
```

## Sample Output 1

```text
Tuesday
```

## Sample Input 2

```text
8
```

## Sample Output 2

```text
Invalid
```
