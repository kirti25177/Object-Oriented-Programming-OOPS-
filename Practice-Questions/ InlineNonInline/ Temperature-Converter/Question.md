# Temperature Converter Using Inline and Non-Inline Member Functions

## Problem Statement

A weather forecasting application needs to convert temperatures from Celsius to Fahrenheit and Kelvin.

Write a C++ program using a class named `TemperatureConverter` that stores the temperature in Celsius and calculates its equivalent Fahrenheit and Kelvin values.

Demonstrate inline and non-inline member functions in the class.

Use the following formulas:

- Fahrenheit = (9.0 / 5.0) × Celsius + 32
- Kelvin = Celsius + 273.15

## Input Format

A single double value representing the temperature in Celsius.

## Output Format

Print the following on separate lines, with values rounded to two decimal places:

- `Temperature in Fahrenheit: <value>`
- `Temperature in Kelvin: <value>`
