# Letter Analyzer Using Enum

## Problem Statement

Vasanth is developing a letter analyzer program. Write a C++ program that uses an enumeration (`enum`) to classify a single character as a vowel, consonant, or invalid input.

The program must handle both uppercase and lowercase letters.

## Input Format

A single character, which may be an uppercase letter, lowercase letter, digit, or special character.

## Output Format

- Print `vowel` if the character is a vowel.
- Print `consonant` if the character is an alphabetic consonant.
- Print `Invalid input` if the character is not an alphabetic letter.
