# Employee Information Using Structure

## Problem Statement

Farhana is learning about structures and wants to store employee information using a structure named `Employee`.

Write a C++ program to read the employee's ID, name, date of birth (DOB), date of joining (DOJ), and salary. Display all the entered information in the specified format.

## Input Format

1. An integer representing the employee ID.
2. A string representing the employee's name.
3. A string representing the date of birth in `dd/mm/yyyy` format.
4. A string representing the date of joining in `dd/mm/yyyy` format.
5. A double value representing the employee's salary.

## Output Format

Print the following details, each on a new line:

- `ID : <employee ID>`
- `Name : <name>`
- `DOB : <date of birth>`
- `DOJ : <date of joining>`
- `Salary : <salary>` — rounded to one decimal place.
