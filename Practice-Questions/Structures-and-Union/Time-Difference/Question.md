# Time Difference Using Structure

## Problem Statement

Kishen needs to calculate the difference between two given times. Write a C++ program that defines a structure named `Time` and calculates the difference between two times entered by the user.

The result must be displayed in `HH:MM:SS` format, with zero padding for single-digit hours, minutes, and seconds.

## Input Format

Two lines of input, each containing a time in `HH:MM:SS` format.

- The first line represents time T1.
- The second line represents time T2.

## Output Format

Print the difference between T1 and T2 in `HH:MM:SS` format, with two digits for hours, minutes, and seconds.

## Constraints

- 0 ≤ hours ≤ 23
- 0 ≤ minutes, seconds ≤ 59
- T1 > T2
