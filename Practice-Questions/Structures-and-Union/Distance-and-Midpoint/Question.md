# Distance and Midpoint of a Line Segment

## Problem Statement

Sharukh needs to calculate the distance and midpoint of a line segment given its endpoints. Write a C++ program that reads the coordinates of two endpoints, calculates the distance between them, and finds the midpoint.

## Formulas

- Distance = √((x₂ − x₁)² + (y₂ − y₁)²)
- Midpoint = ((x₁ + x₂) / 2, (y₁ + y₂) / 2)

## Input Format

- The first line contains two integers, `x1` and `y1`, representing the first endpoint.
- The second line contains two integers, `x2` and `y2`, representing the second endpoint.

## Output Format

- The first line prints `Distance: ` followed by the distance rounded to two decimal places.
- The second line prints `Midpoint: ` followed by the midpoint coordinates, each rounded to two decimal places.
