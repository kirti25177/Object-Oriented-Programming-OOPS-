# Circle Area and Circumference Using Structure

## Problem Statement

Write a C++ program to calculate the circumference and area of a circular garden using a structure named `Circle`.

Use the following formulas, assuming PI = 3.14:

- Circumference = 2 × PI × radius
- Area = PI × radius²

Use the `pow()` function from the math library to calculate the square of the radius. Display both results rounded to two decimal places.

## Input Format

A single double value representing the radius of the circle.

## Output Format

- The first line displays the circumference rounded to two decimal places.
- The second line displays the area rounded to two decimal places.
