# Customer Balance Update Using Union

## Problem Statement

Raju is developing a banking system that stores customer information using a union named `Customers`.

The program processes exactly three customers. Each customer has a customer ID, account number, and balance.

If a customer's balance is greater than Rs. 1000, increase their balance by Rs. 100 and print the updated balance.

All processing must be performed directly inside the `main()` function without using separate functions.

## Input Format

The input consists of three lines. Each line contains three integers separated by spaces:

1. Customer ID
2. Account number
3. Balance

## Output Format

Print the updated balances of customers whose original balances are strictly greater than Rs. 1000. Separate the balances with a single space.
