# Patient Information Using Structure

## Problem Statement

A hospital wants to store information about its patients. Create a structure named `patient` to store each patient's ID, gender, and age.

Gender is represented as:
- `1` for Male
- `2` for Female

There are exactly 10 patients visiting the hospital.

Write a program to accept the information of all 10 patients and calculate the total number of male and female patients. Also, count the patients whose age is greater than 40.

## Input Format

The input consists of exactly 10 lines. Each line contains three space-separated integers:

`ID gender age`

- `ID`: Patient ID
- `gender`: 1 for Male or 2 for Female
- `age`: Patient's age

## Output Format

- The first line displays the number of male and female patients, separated by a space.
- The second line displays the number of patients whose age is greater than 40.

## Sample Input

```text
101 1 45
102 2 35
103 1 50
104 2 42
105 1 30
106 2 25
107 1 65
108 2 55
109 1 40
110 2 48
```

## Sample Output

```text
5 5
7
```

## Concepts Used

- Structures
- Arrays of Structures
- Loops
- Conditional Statements
- Counting and Comparison
