# Robot Navigation Using Enum and Switch

## Problem Statement

Zara is developing a navigation system for a robot. Integer values represent the four cardinal directions. Write a C++ program that defines an enumeration named `Direction` and uses a `switch` statement to print the corresponding navigation instruction.

## Direction Mapping

- 1 — North
- 2 — East
- 3 — West
- 4 — South

## Input Format

A single integer `n` representing the direction.

## Output Format

For a valid direction, print:

`We are headed towards <direction>`

If the input is invalid, print:

`Invalid Input`

## Constraints

0 ≤ n ≤ 100
