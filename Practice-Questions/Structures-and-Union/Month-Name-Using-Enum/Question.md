# Month Name Using Enum and Switch

## Problem Statement

Kim is creating a calendar application to manage and display the months of the year.

Write a C++ program that defines an enumeration named `Month` to represent the twelve months. Read a month number, validate it, and display the corresponding month name in uppercase using a `switch` statement.

If the input is invalid, display the specified error message.

## Input Format

A single integer `n` representing the month number.

## Output Format

- For a valid month number from 1 to 12, print `Month: <MONTH_NAME>` with the month name in uppercase.
- For an invalid month number, print `Invalid month input`.
